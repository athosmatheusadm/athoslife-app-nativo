# Catálogo — o que cada lista trouxe pro ATHOSlife (lidas em 2026-10-09)

Das 4 listas, só entrou o que serve pra app de celular em React + Tailwind,
tema escuro, com mascote. O resto (templates de site, landing page, Vue,
Angular, Bootstrap, stock de foto/vídeo, cursos pagos) ficou de fora.

## 1. bradtraversy/design-resources-for-developers
- **Laws of UX** — leis de UX (Fitts, Hick, Jakob, proximidade). Base dos princípios da skill.
- **Checklist Design** — checklists por componente (botão, formulário, card, onboarding).
- **Humane By Design** — padrões de produto que cuidam do bem-estar (sem vício, sem culpa). Combina com o Life.
- **Huetone**, **Colorlab**, **ColorOf** — paleta acessível e checagem de contraste.
- **UI Colors** — gera escala de cor no formato Tailwind a partir de 1 cor.
- **Framer Motion** (hoje "motion"), **React Spring** — animação em React.
- **Tabler Icons**, **Heroicons**, **Iconoir**, **Feather** — ícones SVG.
- **Lordicon**, **UseAnimations** — ícones animados (Lottie).
- **Material Design**, **Apple Design Resources** — convenções de celular.
- Inspiração: **Screenlane**, **Collect UI**, **Foxyapps**, **Design Vault**.

## 2. reinaldosimoes/design-resources
- **Mobbin**, **Page Flows**, **Refero** — telas e fluxos reais de apps (melhor fonte pra comparar Dieta/Treino com mercado).
- **LottieFiles**, **Lordicon**, **Jitter** (cria Lottie no navegador).
- **Rive** — animação interativa com máquina de estados (candidato pro Life mudar de humor sem trocar imagem).
- **Lucide**, **Phosphor**, **Material Symbols**, **Ionicons** — ícones.
- **Realtime Colors**, **Huemint** — ver a paleta aplicada numa tela antes de decidir.
- **shadcn/ui**, **Radix UI**, **Headless UI**, **21st.dev**, **Magic UI**, **Aceternity UI** — componentes Tailwind (Magic/Aceternity são mais pra landing page; usar com moderação).
- **web.dev Learn** — acessibilidade e performance.
- Design systems: Material, Human Interface Guidelines, Fluent 2.

## 3. birobirobiro/awesome-shadcn-ui
Ecossistema shadcn (copiar e adaptar; muitos são Tailwind 4 — converter tokens).
- **vaul** — drawer/sheet de baixo com arrastar.
- **sonner**, goey-toast — toasts.
- **number-flow** — transição de número.
- **react-wheel-picker** — roleta estilo iOS.
- **stateful-button**, **progress-button** — botão com carregando/sucesso.
- **shadcn-calendar-heatmap** — mapa de calor de dias.
- **shadcn-stacked-progress-bar** — barra com várias partes (macros do dia).
- **tour**, **user-tour-kit**, onborda — tour de primeira vez.
- **shadcn-stepper** — passos (check de saúde, onboarding).
- **loading-ui** — loaders e skeletons.
- Animação: **animate-ui**, **tailwindcss-motion**, motion-lexicon (com fallback de reduced motion), animata.
- Biblioteca maior: **kibo-ui**, **dice-ui**, **cult-ui**, **creatorem/ui** (Tour, Stepper, diálogo que imita o nativo).
- Tema: **tweakcn**, shadesigner, ewgenius/ui (Radix Colors).

## 4. uhub/awesome-css
Lista de repositórios CSS genéricos — pouco pra nós.
- **Checka11y.css**, **diagnosticss** — CSS de diagnóstico de acessibilidade (só em dev).
- **codrops/ClickEffects** — efeitos de toque (inspiração pro feedback de botão).
- **SpinKit**, **css-loaders** — loaders em CSS puro.
- **codyhouse/dark-light-mode-switch** — se um dia tiver tema claro.
